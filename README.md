# 📱 Phone Mode

SillyTavern 手机聊天界面扩展，在酒馆里召唤一个完整的手机 UI。

## 安装

打开 SillyTavern → 扩展 → 从 URL 安装，粘贴：

```
https://github.com/K20070831/sillytavern-phone-mode-1
```

## 基础用法

| 操作 | 说明 |
|------|------|
| `/phone` | 召唤 / 关闭手机界面 |
| `你好/在吗` | `/` 分隔发多条消息 |
| `(转账+50)` | 转账气泡 |
| `(图片+描述)` | 图片占位（可配合 AI 生图自动填充） |
| `(语音+文字)` | 语音条气泡 |
| `[emo:组名:序号]` | 表情包 |

## 功能

**微博**：内置类微博系统，支持发博、评论、点赞、关注。档位分素人 / 不火 / 顶流，控制互动数量级。群聊模式下多成员各有独立身份，时间线合并展示。

**备忘录 / 日记**：AI 自动生成角色视角的日记或备忘条目，支持涂黑遮挡文字，点击揭开。

**TTS 语音**：语音条内置 🔊 按钮，支持 OpenAI、MiniMax、豆包/火山引擎三种接入。

**AI 生图**：聊天气泡和微博均可一键生成配图，支持 OpenAI 兼容接口和 NAI。

**群聊**：多联系人 / 群聊切换，群聊支持独立成员身份和群微博。

**外观定制**：气泡主题、背景图、机身边框效果（磨砂 / 半透明 / 描边），日间 / 夜间切换。

**设置**：导航栏 ⚙ 进入，分 API / 外观 / 图像 / 其他 四个标签页。TTS 配置在「其他」，生图配置在「图像」。

## 说明

- 纯前端，无需后端，兼容 TauriTavern
- 图片存 IndexedDB，每个角色上限 30 张，全局 300 张，超限自动删最旧的
